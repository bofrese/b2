# 2026 emerging trends

Dated activation index. **These age fastest - verify at build time before leaning on them.** Style→business
mapping lives in `styles-and-business.md`.

- **Tactile brutalism** - raw-but-precise; physical/engineered components replacing floating soft-UI. Counter-movement to polished bento.
- **Bento grids (matured)** - now a layout foundation, not a novelty.
- **Spatial UX / dimensionality** - buttons-as-objects, stackable cards, weight/tilt/cursor response; cheaper 3D via R3F/Spline.
- **AI real-time personalization** - role-based UX, adaptive nav/landing per behavior; "custom-built per visitor" expectation.
- **Scrollytelling** - scroll-triggered narrative reveals; strong for complex products/case studies.
- **Kinetic typography & variable fonts** - animated/interactive type as the hero focal point, not decoration.
- **Native motion via platform** - View Transitions + scroll-driven CSS + `@starting-style` replacing JS animation libs for common cases.
- **Modern-CSS-driven layout** - container queries, `:has()`, subgrid, `color-mix()`, OKLCH color; less JS.
- **Dark-mode-first (still winning)** with high-chroma/OKLCH accents.
- Reality check (per studiomeyer): bento + dark mode held up; anti-grid brutalism rose; over-animated hero fatigue setting in.
